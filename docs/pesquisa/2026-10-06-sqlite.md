# SQLite nativo para o ranking — 2026-10-06

A pedido explícito do dono, foi comparado SQLite embutido com manter PostgreSQL e adicionar um driver externo.
A decisão aprovada está no [ADR-0003](../decisoes/ADR-0003-sqlite-embutido.md).

## Fontes oficiais consultadas

- [node:sqlite no Node 24.18.1](https://nodejs.org/download/release/v24.18.1/docs/api/sqlite.html): API em
  Stability 1.2 (Release Candidate), sem flag; `DatabaseSync` é síncrono. O timeout nativo foi introduzido em 24.0;
  escolhemos 5000 ms em vez do padrão zero. Parâmetros nomeados incluem `$1`, com objeto de bindings nativo.
- [Código da documentação da versão fixada](https://raw.githubusercontent.com/nodejs/node/v24.18.1/doc/api/sqlite.md):
  modo defensivo padrão ativo desde 24.14 e extensões desativadas. Esses valores são explícitos no adaptador.
- [Licença do Node](https://github.com/nodejs/node/blob/v24.18.1/LICENSE) e
  [licença do SQLite](https://www.sqlite.org/copyright.html): software sem custo de licença; SQLite em domínio público.
- [WAL](https://www.sqlite.org/wal.html): processos precisam do mesmo host e os arquivos auxiliares acompanham o banco.
- [Transações](https://www.sqlite.org/lang_transaction.html): `BEGIN IMMEDIATE` reserva a escrita antes de consultar
  a marca de migração. A espera usa o timeout da conexão; não garante concorrência ilimitada.
- [Backup](https://www.sqlite.org/backup.html): cópia consistente exige API de backup ou ausência de escritor.

Não usamos pacote novo de execução. O runtime precisa ficar fixado e a integração revalidada em atualizações,
pois a API ainda é Release Candidate. Testes usam o motor real, em memória e em arquivos temporários, incluindo
um escritor em processo separado durante migração.

O runtime local fixado informa SQLite 3.53.1 em `process.versions.sqlite`. A documentação WAL registra um bug de reset corrigido desde 3.51.3 (ou backports específicos); 3.53.1 já inclui a correção. Conferir o mesmo valor na imagem antes da publicação.

A tarefa #19 confirmou a imagem oficial Node24.18.1-alpine por digest multiarch f70403e87646dc51b45295f4b8b70cdad0b63d2297c4c9899119b03f7af7a6b3 (manifesto ARM64 9f28ad37052908fb889f5c2494ae572eeeba9a94964ef9f8c735ef088c4ec3e9). O contêiner real informa Node24.18.1/SQLite3.53.1. As [boas práticas oficiais](https://github.com/nodejs/docker-node/blob/main/docs/BestPractices.md) orientam usuário sem privilégio e execução direta do Node para receber sinais; aplicados no empacotamento.
